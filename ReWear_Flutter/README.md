# ReWear the Unexpected — V2

Interactive Flutter mobile mockup: turn everyday objects into unexpected accessories.
V2 is based on reviewer feedback — see [`../REPORT.md`](../REPORT.md).

## Run
```powershell
flutter pub get
flutter run -d edge
```

Recommendations are illustrative and rule-ranked from a synthetic dataset (`assets/data/recommendations.json`), not outputs of a trained ML model. Illustrations are schematic.
